# Data Preparation

The conference experiments use Site1, Site2, and Site4 from the Chinese State Grid
Renewable Energy Generation Forecasting Competition dataset:

Chen, Y. and Xu, J. (2022). *Solar and wind power data from the Chinese State Grid Renewable Energy Generation Forecasting Competition*. Scientific Data, 9, 577. <https://doi.org/10.1038/s41597-022-01696-6>

Obtain the original data through the data-access links in the source paper and
follow the provider's terms. This repository includes the input schema and
fingerprints; prepare the data files separately.

## Directory Layout

```text
datasets/wind/
  grid_wind_site1_99MW.csv
  grid_wind_site2_200MW.csv
  grid_wind_site4_66MW.csv
```

Each row is a 15-minute observation, sorted chronologically. Conference inputs
cover 2019-01-01 through 2020-12-31, with 70,176 rows per site. The timestamp column
is `date`, target power is in MW, and wind-direction columns contain degrees.

Site1 and Site4 use this column order:

```text
date,wind_speed_10m,wind_dir_10m,wind_speed_30m,wind_dir_30m,
wind_speed_50m,wind_dir_50m,wind_speed_hub,wind_dir_hub,
temperature,pressure,humidity,power
```

Site2 uses the same order without `humidity`. Convert other source file formats
or column names to this wide-table schema before running the model. The
fingerprints in `manifest.json` describe the prepared research inputs, not the
provider's original download files.

## Validation

```bash
python scripts/verify_data.py --data-root datasets/wind
python scripts/verify_data.py --data-root datasets/wind --strict-hash
```

The first command checks column order, row count, time intervals, and finite
numeric values, and reports whether the reference fingerprint matches.
`--strict-hash` additionally requires byte-identical CSV files. Changes to line
endings or numeric serialization precision also change the fingerprint.

## Training-Time Processing

`--wind-dir-encoding sincos` replaces each wind-direction column with sine/cosine
columns during loading. The resulting input contains 16 variables for Site1/4
and 15 for Site2. Chronological train/validation/test splits are 70%/10%/20%.
Means and standard deviations are fitted on the training partition only.
Validation/test windows use earlier observations as history where necessary;
forecast targets remain within the corresponding partition.

Keep CSV values in their original physical scale; the loader performs
standardization. Other datasets can be selected with `--root-path`, `--data-path`,
`--time-col`, and `--target`, typically with `--wind-dir-encoding none`.

The synthetic series generated by `scripts/smoke_test.py` are used solely for
software verification, not for the paper's experiments or reported metrics.
