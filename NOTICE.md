# Method References and Release Scope

TELA's runner and experiment/data-provider layout follow the Time-Series-Library
research-code style. The standalone directory does not vendor the baseline projects.
Relevant methodological references include:

- Time-Series-Library: <https://github.com/thuml/Time-Series-Library>
- PatchTST (patch-based time-series representation): <https://github.com/yuqinie98/PatchTST>
- RevIN (optional reversible instance normalization): <https://github.com/ts-kim/RevIN>
- The original Transformer sinusoidal positional representation, used in the patch embedding.

TELA source code is distributed under the MIT License in `LICENSE`.
The references above identify methodological context. Any applicable upstream
licenses and copyright notices continue to apply to third-party material.

Dataset access and reuse follow the original data provider's terms:
<https://doi.org/10.1038/s41597-022-01696-6>.
